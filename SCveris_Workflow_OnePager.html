The 10 AQEM Workflows

1. MFG Issue Report

The front door — low barrier, any operator
Initiation → QA Triage → [Close / DEV / NC / OOS]
Owner: QA (triage) Initiator: Any operator SLA: Triage 24h

2. Deviation

Unplanned departure from SOP, spec, or expected outcome
Initiation → Correction → Investigation → Risk Assessment → [Close / CAPA]
Owner: Mace Windu SLA: Investigation 15 days

3. Nonconformance

Material or product failing specification
Initiation → Investigation → Disposition → [Reject / Rework / Use-As-Is] → [SCAR? / CAPA?]
Owner: Mace Windu SLA: Disposition 5 days

4. OOS Investigation

Out-of-specification lab result — structured phase-based
Notification → Phase I (Lab) → [Lab error? Y→Close] → Phase II (Full) → Disposition
Owner: QC Supervisor SLA: Phase I: 3 days, Phase II: 20 days

5. CAPA

Root cause + corrective/preventive actions — the systemic fix
Initiation → Root Cause → Action Plan → Implementation → Effectiveness → [30/60/90d]
Owner: Padmé Amidala Approver: VP Quality Can trigger: Change Control

6. Change Control

Controlled change to process, document, equipment, or material
Proposal → Impact Assessment → Approval → Implementation → Verification
Owner: Process Owner Qx Integration: Auto doc revision + training assignment

7. Customer Complaint

External complaint — intake, investigate, respond
Intake → Classification → Investigation → Response → [CAPA? / Market Action?]
Owner: Leia Organa (RA) SLA: Intake 24h, Investigation 30 days

8. SCAR

Supplier Corrective Action Request
Issuance → Supplier Response → [Adequate?] → Verification → Close
Owner: Han Solo SLA: Supplier response 30 days

9. Audit Observation

Internal/external audit finding requiring response
Finding → Response Plan → Implementation → Verification → [CAPA?]
Initiator: C-3PO (auditor) Owner: Mace Windu

10. Market Action / Field Safety

Recall, field correction, or safety notification — the nuclear option
Signal → Classification → Regulatory Notification → Execution → Effectiveness
Owner: Padmé + Leia Approver: Mon Mothma (CEO) SLA: Class I notification 24h

Configuration Principles
1
MFG Issue Report is the front door. Operators should never hesitate to report. No classification required at initiation. QA triages within 24h.
2
Every workflow links back. No orphan events. Every CAPA traces to a source. Every Change Control traces to a CAPA or business justification.
3
Escalation, not duplication. When an MFG Issue Report becomes a Deviation, the original links — data carries forward, nothing is re-entered.
4
SLAs are configurable but defaulted. Triage: 24h. Investigation: 15 days. CAPA effectiveness: 30/60/90 days. Starting points, not hard limits.
5
Qx integration is automatic. Change Controls that revise documents auto-trigger training in Qx. The most powerful cross-module demo moment.
6
Risk-based classification. Minor deviations close without CAPA. Major/Critical require CAPA assessment. Not everything needs the full cascade.
7
Market Action is the nuclear option. Requires CEO approval (Mon Mothma) and regulatory notification. Exists for completeness — rarely the primary demo path.
