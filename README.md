# SCveris Group — Demo Instance Site

A static site for the **SCveris Group** MasterControl demo environment,
published via GitHub Pages.

**Live site:** https://erothermc.github.io/SCveris/

---

## What is this?

SCveris Group is a **fictional** diversified life sciences and regulated
manufacturing conglomerate, created as a flexible demonstration environment for
MasterControl Manufacturing (Mx), Quality (Qx), and Asset Management (Ax).

This repository hosts the public-facing overview page plus a set of one-pagers
that provide the detail behind the demo instance.

> **Same instance. Same data. Different lens.**
> One environment that can be framed to mirror virtually any regulated
> manufacturing prospect: pharma, biopharma, medical devices, diagnostics, or
> food and beverage.

## Editing the site

Each page is a self-contained HTML file. To update one:

1. Open the file in the repo and click the pencil (Edit) icon, or edit locally.
2. Make your changes and commit to the `main` branch.
3. Wait 1 to 2 minutes for GitHub Pages to rebuild, then hard-refresh (Ctrl+F5).

---

## How it is published

- Hosted on **GitHub Pages**.
- **Source:** Deploy from a branch → `main` → `/ (root)`.
- The homepage loads automatically because it is named `index.html` at the repo root.
- The site is public and requires no login to view.

---

## A note on filenames

Some files contain spaces, which appear as `%20` in their URLs. For cleaner
links, consider renaming them without spaces (for example,
`corporate-one-pager.html`), then update any links in `index.html` to match.
